# 📚 Library Management System

A Java Servlet-based Library Management System designed to manage students, books, book issuing, and book returns efficiently.

## 🚀 Features

- 🔐 User Login
- 👨‍🎓 Student Registration
- 📚 Add and Manage Books
- 📖 Issue Books
- 🔄 Return Books
- 👥 View Students
- 📋 View Issued Books
- 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

- Java
- Jakarta Servlets
- Apache Tomcat
- MySQL
- HTML
- CSS
- JDBC
